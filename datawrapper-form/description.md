#### Automated Datawrapper workflow for newsrooms:

With a basically formatted CSV, newsrooms can upload data to the tool using a Streamlit-built front-end and create a

correctly-formatted interactive graphic within minutes. If only addresses are provided to location maps, the tool

automatically geocodes them and returns coordinates in WSG84 coordinate standard, which is more precise for Datawrapper maps.

Because of hosting limitations with Snowflake, this tool uses a custom-built Datawrapper API.
